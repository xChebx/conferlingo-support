Getting started

  1. Add your OpenAI API key on the first launch or in Settings.
  2. Allow microphone access. On Mac, also allow System Audio Recording when prompted.
  3. For spoken iPhone Live translation, connect AirPods or another Bluetooth headset before starting.
  4. Select a direction and start recording. Stop waits for the captured tail and finishes the translation.

System audio on Mac

Open System Settings → Privacy & Security → Screen & System Audio Recording and enable ConferLingo. The app captures audio only; it does not save or process the image of your screen.

Headphones

ConferLingo uses standard iOS audio routing. AirPods and compatible Bluetooth headphones work without proprietary hardware. Split-ear Dialogue requires a real stereo output and Mono Audio to be disabled.

OpenAI billing

The App Store purchase does not include OpenAI usage. Requests are sent directly from your device using your own OpenAI API key, and OpenAI charges your API account separately.

Important translations

Machine translation can be inaccurate. Review contract terms, safety instructions, medical information, and other high-impact content with a qualified human interpreter.
